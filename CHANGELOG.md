# Changelog

How versions work: the number lives in the `VERSION` file. To release, change it,
add a section here, then run `python tools/build.py`. The build copies it into the
menu badges and the README.

- **2.0** for a big update (new worlds, new systems)
- **2.1, 2.2 …** for normal updates
- Fixes in between can just ride along with the next number

## V2.0 (16 Nov 2026)
Fresh start for version numbers. Everything built so far is in this release:
tile editor and campaign builder, 7 themed worlds with parallax and music,
enemies and minibosses, weapons and power-ups, grapple, new moves, world twists,
live lighting and game feel, blob skins, lives/HP and level-complete ranks,
touch, gyro, gamepad and mobile editor, offline play.
(Older code comments used to carry internal tags up to V6.8; those were removed.)
